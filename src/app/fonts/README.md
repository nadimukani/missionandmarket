# Fonts

Served from the site itself so builds never depend on Google Fonts.

| File | Family | Axes used |
| --- | --- | --- |
| `noto-serif-display-latin.woff2` | Noto Serif Display, upright | weight 300–400 |
| `noto-serif-display-italic-latin.woff2` | Noto Serif Display, italic | weight 300–400 |
| `jost-latin.woff2` | Jost | weight 300–500 |

The latin subset files Google Fonts serves (variable fonts), loaded with
`next/font/local` in `src/app/layout.tsx`. Both are licensed under the SIL Open
Font License 1.1: see `OFL-NotoSerifDisplay.txt` and `OFL-Jost.txt`.
